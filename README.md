# 💻 Personal Blog

A modern and responsive **personal blog and portfolio website** built with React, designed to introduce the developer, showcase technical skills, and display personal projects.

## ✨ Features

* 🏠 Personal introduction and About Me section
* 🛠️ Showcase technical skills
* 📂 Display personal projects
* 🧭 Navigation between different pages
* 📱 Responsive design for different screen sizes
* 🍔 Responsive hamburger menu for mobile devices
* ❌ Custom 404 / Page Not Found page
* 🎨 Simple and modern user interface

## 🛠️ Technologies Used

* HTML
* CSS
* JavaScript
* React
* React Router
* React Icons
* CSS Modules
* Vite
